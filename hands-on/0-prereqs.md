# 演習 0: 環境のセットアップと前提条件

| [次の手順: GitHub Issue の作成 →](./1-github-issue-creation.md) |
|--:|

この演習では、GitHub Copilot エージェントを使用した旅行アプリケーション開発に必要な環境と前提条件を確認します。

## シナリオ

開発チームの新メンバーとして、既存の旅行アプリケーションプロジェクトに参加し、GitHub Copilot エージェントの機能を活用した開発ワークフローを学習します。まずは作業環境が適切にセットアップされていることを確認しましょう。

## ? 旅行アプリケーションの概要

このハンズオンで使用するのは、**Next.js** で構築された包括的な旅行アプリケーションです。

### 主要機能
- **旅行検索・予約**: 目的地やカテゴリでの高度な検索機能
- **旅行ガイド**: エキスパートによる目的地の詳細ガイド  
- **予約管理**: ユーザーの予約履歴と管理機能
- **ポイントシステム**: ロイヤルティプログラムとポイント追跡

### 技術仕様
- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **アーキテクチャ**: サーバーコンポーネント & クライアントコンポーネント

## 環境要件の確認

### ? 必須 1. GitHub アクセスの確認

1. GitHub アカウントにログインしていることを確認
2. 対象リポジトリへのアクセス権限があることを確認
3. Issues の作成・編集権限があることを確認

### ? 必須 2. GitHub Copilot エージェント機能の確認

1. リポジトリで Copilot エージェント機能が有効になっていることを確認

### ? 参考 3. 開発環境（参考情報）

> [!NOTE]
> このハンズオンではコードの動作確認は省略しますが、実際の開発では以下の環境が必要です：

- Node.js 18.0 以上
- npm または yarn パッケージマネージャー
- Git バージョン管理システム
- Visual Studio Code（推奨）+ GitHub Copilot 拡張機能

## ? プロジェクト構造の理解

現在のプロジェクト構造を確認しておきましょう：

```
旅行アプリケーション/
├── app/                    # Next.js App Router
│   ├── layout.tsx         # ルートレイアウト
│   ├── page.tsx           # ホームページ
│   ├── bookings/          # 予約管理ページ
│   ├── guides/            # 旅行ガイド
│   ├── points/            # ポイント管理
│   └── trips/             # 旅行検索・詳細
├── components/            # 再利用可能コンポーネント
│   ├── layout/           # ヘッダー・フッター
│   ├── trips/            # 旅行関連UI
│   ├── bookings/         # 予約関連UI
│   └── ui/               # 基本UIコンポーネント
├── lib/                  # ユーティリティとデータ
│   ├── data/            # モックデータ
│   ├── services/        # APIサービス
│   └── types/           # TypeScript型定義
└── public/              # 静的アセット
```

## ? 今回実装する機能の概要

このハンズオンでは、以下の2つの主要機能を GitHub Copilot エージェントと協働で実装します：

### 機能1: サポートメニューの実装
- FAQ ページ
- 問い合わせフォーム
- 連絡先情報ページ

### 機能2: 検索フィルターの拡張
- 国別検索フィルター
- 新カテゴリ「Food」の追加

以下の項目をすべて確認してから次のステップに進んでください：

- [ ] 対象リポジトリの Issues ページが表示できる
- [ ] 新しい Issue の作成が可能

- [ ] 実装予定の機能について理解した

## まとめと次のステップ

環境の確認が完了しました。次のステップでは、実際に GitHub Issue を作成し、Copilot エージェントに実装を依頼するプロセスを学習します。

Issue 作成では、要件の明確な定義と技術仕様の詳細化が重要になります。適切な Issue により、Copilot エージェントは高品質なコードを生成できます。
