# GitHub Copilot エージェントを使用した旅行アプリケーション開発

GitHub Copilot エージェントの AI アシスタント機能を活用して、旅行アプリケーションに新機能を効率的に実装する方法を学習します。Issue の作成、Copilot エージェントへの割り当て、およびAI駆動開発のワークフローを実践的に体験します。

## ラボの概要

> [!IMPORTANT]
> このラボの技術や生成AIツールは確率論的であるため、スクリーンショットや
> コードスニペットと実際の体験に違いが生じる可能性があります。

このラボでは、GitHub Copilot エージェントと協働して旅行アプリケーションの新機能開発を順を追って説明します。

## シナリオ

あなたは旅行アプリケーションの開発チームの一員です。現在のアプリケーションは Next.js で構築されており、旅行検索・予約、旅行ガイド、予約管理、ポイントシステムなどの機能を持っています。

市場からの要求により、以下の新機能の追加が求められています：
- **サポートメニュー**: FAQ、問い合わせフォーム、連絡先情報を含む包括的なサポートセクション
- **高度な検索フィルター**: 国別検索と新しいカテゴリ（Food）の追加

これらの機能を従来の手動開発ではなく、GitHub Copilot エージェントを活用して効率的に実装することが今回のミッションです。

## 学習目標

このハンズオンを完了すると、以下ができるようになります：
- GitHub Issue を効果的に作成し、要件を明確に定義する
- Copilot エージェントに適切にタスクを割り当てる
- AI生成コードの品質を評価し、適切なフィードバックを提供する
- AI駆動開発のワークフローを理解し、実践する
